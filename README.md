An entry for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479).

The program writes one two-line explanation to `/output/entry.txt`:
line 1 explains a traffic jam to a 10-year-old in a single vivid
sentence built on an analogy (a school corridor at the bell, a hundred
kids squeezing through one door); line 2 says in one sentence why that
analogy works — what it maps and what it leaves out.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program validates the entry itself before writing: UTF-8 text,
1–400 characters, exactly two non-empty lines. It prints the character
count (359) and writes `/output/entry.txt`.
